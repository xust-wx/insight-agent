## 1. 阶段演进记录

## 3. 进入 S1 的前置条件（需用户就绪）
1. 复制 `.env.example` 为 `.env`，填入阿里云百炼 `DASHSCOPE_API_KEY`。
2. 下载 Kaggle Olist 数据集压缩包放入 `data/raw/olist.zip`。
3. 启动 Docker Desktop 守护进程。
